Tune Finder

Search a Forza Horizon 6 car and this pulls two things at once: a hand-verified seed set of tuning share codes, and a live search-engine query across community tune sites for that exact car.

How this works.

The Seeded tunes panel is a small, hand-checked set of real share codes — car, class, discipline, code, tuner, upvotes — pulled from fh6tunes.app and Forza Horizon Hub. It currently covers — cars out of the ~647 in FH6.

The Live search results panel calls a real search-engine API (Google Programmable Search) at request time, scoped to tune-code sites, for whatever car you type — including cars not in the seed set. Results are raw search snippets with a best-effort 9-digit code extracted by pattern match; always double-check the code against the linked page before using it in-game.
